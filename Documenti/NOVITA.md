# NOVITA

Questo file raccoglie **tutte le modifiche effettuate nel progetto**, organizzate in ordine cronologico.  
Serve per tenere traccia di ciò che è stato aggiunto, corretto o migliorato dopo ogni task.

Ogni sviluppatore deve **aggiornare questo file immediatamente dopo aver completato una modifica**, come indicato in `ORGANIZZAZIONE.md`.

---

## 🧪 Cosa scrivere in questo file

Per ogni modifica, aggiungere una voce con:

- **Data**
- **Autore**
- **Branch**
- **Descrizione breve**
- **Dettagli della modifica**

---

## 📌 Linee guida

- Scrivere in modo chiaro e sintetico  
- Evitare paragrafi troppo lunghi  
- Ogni modifica deve essere una nuova sezione  
- Le modifiche devono essere elencate **dalla più recente alla più vecchia**  
- Se una modifica riguarda più file, elencarli brevemente  

---

## 📚 Scopo del file

- Tenere traccia dell’evoluzione del progetto  
- Permettere agli sviluppatori di capire rapidamente cosa è cambiato  
- Facilitare debugging e revisione del codice  
- Rendere più semplice la collaborazione tra più persone  

---

## 🔄 Note finali

- Aggiornare questo file è **obbligatorio** dopo ogni task  
- Se una modifica è molto grande, suddividerla in più punti  
- Se una modifica deriva da una proposta, indicare il riferimento a [Proposte](PROPOSTE.md)

---
