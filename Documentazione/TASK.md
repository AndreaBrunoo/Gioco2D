# TASK

Questo file contiene **tutte le task del progetto**, organizzate per stato.  
Serve per sapere cosa c’è da fare, cosa è in corso e cosa è stato completato.

Ogni sviluppatore deve aggiornare questo file quando:

- prende in carico una task  
- completa una task  
- aggiunge una nuova attività  
- sposta una task da una sezione all’altra  

---

# 🧭 Linee guida

- Una task deve essere **chiara e specifica**  
- Non inserire task troppo generiche  
- Ogni task deve avere **un solo obiettivo**  
- Quando una task è completata, ricordarsi di aggiornare anche [Novità.](NOVITA.md ) 
- Se una task deriva da una proposta, indicare il riferimento a [Proposte.](PROPOSTE.md ) 

---

# 🎯 Obiettivo del file

- Evitare sovrapposizioni tra sviluppatori  
- Tenere traccia dello stato del lavoro  
- Rendere chiaro cosa è prioritario  
- Facilitare la collaborazione e la pianificazione  

---

## 📌 Come usare questo file

Ogni task deve contenere:

### **Titolo breve**
- **Descrizione:**
- **Autore:**
- **Branch associato:**
- **Stato:**

### Esempio: **Sistemare paginazione inventario**
- **Descrizione:** correggere bug nella visualizzazione dei consumabili.
- **Autore:** Andrea
- **Branch:** paginazione-inventario
- **Stato:** In corso
